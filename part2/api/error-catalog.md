# 错误与恢复目录

HTTP状态配合稳定code处理；404或网络错误不能被客户端改写成从未提交。各读接口不涉及业务提交时使用不可返回。

| 编码 | HTTP状态 | 中文标题 | 提交状态 | 恢复策略 |
|---|---|---|---|---|
| `INVALID_REQUEST` | 400 | 请求格式不正确 | 未提交 | 修正后重新预览 |
| `AUTH_REQUIRED` | 401 | 请重新验证身份 | 不可返回 | 重新登录 |
| `PURPOSE_NOT_ALLOWED` | 403 | 当前用途未获允许 | 未提交 | 停止 |
| `RESOURCE_NOT_VISIBLE` | 404 | 对象不存在或当前不可访问 | 不可返回 | 停止 |
| `RECEIPT_NOT_FOUND` | 404 | 当前未查到可返回的回执 | 结果待核对 | 查询原回执 |
| `VERSION_CONFLICT` | 409 | 对象已发生变化 | 未提交 | 修正后重新预览 |
| `DRAFT_CHANGED` | 409 | 核对内容或草稿已改变 | 未提交 | 修正后重新预览 |
| `IDEMPOTENCY_KEY_REUSED` | 409 | 同一操作标识对应不同内容 | 不可返回 | 修正后重新预览 |
| `CURSOR_STALE` | 409 | 分页数据截点已变化 | 不可返回 | 停止 |
| `SNAPSHOT_CHANGED` | 409 | 回顾或证据截点已变化 | 未提交 | 修正后重新预览 |
| `PREVIEW_EXPIRED` | 410 | 确认预览已到期 | 未提交 | 修正后重新预览 |
| `TASK_EXPIRED` | 410 | 临时任务已到期 | 未提交 | 停止 |
| `MEDIA_EXPIRED` | 410 | 临时图片已到期 | 不可返回 | 停止 |
| `DOWNLOAD_EXPIRED` | 410 | 导出文件已到期 | 不可返回 | 停止 |
| `STATUS_ACCESS_EXPIRED` | 410 | 本次删除进度凭证已到期 | 不可返回 | 停止 |
| `MEDIA_TOO_LARGE` | 413 | 材料超过当前处理限制 | 未提交 | 停止 |
| `UNSUPPORTED_MEDIA` | 415 | 请选择支持的图片格式 | 未提交 | 停止 |
| `SCHEMA_INVALID` | 422 | 字段结构或值不正确 | 未提交 | 修正后重新预览 |
| `MISSING_VERSION_GUARD` | 422 | 修改已有对象须带所见版本 | 未提交 | 修正后重新预览 |
| `BUSINESS_RULE_BLOCKED` | 422 | 当前内容不满足业务条件 | 未提交 | 修正后重新预览 |
| `BUDGET_EXHAUSTED` | 429 | 本步骤的调用预算已用尽 | 未提交 | 停止 |
| `CONCURRENCY_LIMIT` | 429 | 当前请求较多，请稍后继续 | 未提交 | 稍后查询 |
| `SOURCE_UNAVAILABLE` | 503 | 资料来源暂不可用 | 未提交 | 停止 |
| `STORE_BUSY` | 503 | 当前无法可靠处理数据 | 结果待核对 | 查询原回执 |
| `COMMIT_OUTCOME_UNKNOWN` | 503 | 提交结果仍需核对 | 结果待核对 | 查询原回执 |

补充约束：

- 查询原回执仍不可用时保持结果待核对，不新造操作标识重做。已验证本人归属且原预览仍有效时，才允许按原键重试。
- 业务缺口通常先由预览返回待核对项并隐藏确认令牌；绕过预览或提交时条件变化仍会被服务器阻止。
- 非本人对象统一404，不返回当前版本、字段差异、姓名或来源是否存在。
- 导出和删除的提交回执只说明已受理任务。删除进度凭证也不能下载文件、读旧事实或查看其他任务。
