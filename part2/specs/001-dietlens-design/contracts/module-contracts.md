# 模块交互契约

版本：P3用例语义已沿用为基线。此处保留模块行为；P5的HTTP路径、状态码和载荷统一见[接口契约](../../../api/openapi.yaml)与[接口正文](../../../docs/design/06-api-design.md)，本轮候选待P5确认。

## 公共命令封套

服务端内部命令上下文包含认证主体、任务标识、操作标识、服务端请求摘要、目标归属、预期对象版本及确认草稿版本。外部确认请求只引用已核对预览，不能自报可信主体、修改业务内容或以自算摘要替代服务端绑定。服务端重建可信主体，不接受前端自报用户标识作为授权依据。成功返回提交回执及新版本；版本冲突返回待核对差异；候选过期、权限不足、来源不完整及预算耗尽明确阻断。取消不写业务事实。

外部查询在写事务外执行。事务内锁定处理控制、复核授权和版本、完成领域校验，原子写入事实及回执。同键同摘要在授权仍满足时返回原结果；同键异摘要拒绝。版本冲突必须重新核对，不能自动覆盖。

| 接口职责 | 必要输入 | 成功结果及不变量 | 失败与协作 |
|---|---|---|---|
| 档案与授权：确认档案/变更用途 | 已核对字段、用途、预期版本 | 确认版本及当前处理范围 | 版本冲突；影响候选与回顾有效性 |
| 食品证据：取得/核对候选 | 食品标识、单位、字段、来源 | 逐字段来源及完整性，不补造缺失值 | 来源不可用或缺字段时阻断相关结论 |
| 计划与准备：确认/替换 | 完整或指定模式、槽位集合、多食材、人数、版本 | 只替换确认的日期与餐次；原版本保留 | 有影响的清单标过期；已购状态需重新确认 |
| 计划与准备：确认清单/库存 | 来源计划版本、数量单位、人工操作 | 明确的准备事实 | 不写个人实际摄入；不隐式迁移旧状态 |
| 实际餐食：确认/修订 | 个人日期餐次、多个食物条目、份量、预期版本 | 一次用餐一条记录、多条食物；槽位覆盖去重 | 取消不保存；修订使相关回顾失效 |
| 微行动：采纳/调整窗口 | 行动内容、开始结束、确认版本 | 一个行动标识、明确反馈窗口 | 窗口修订重算原/新队列，不移动执行日期 |
| 微行动：反馈/更正 | 行动标识、执行日期、状态、自述版本 | 同一行动的有效执行修订 | 已采纳历史反馈不受新建议资格变更阻断 |
| 回顾查询：计算期间 | 当前主体、用途授权、日期范围 | 事实版本截点、执行周指标、结束队列反馈率 | 未知不填零；无授权不使用相关历史 |
| 期限与数据控制：撤回/删除 | 当前确认与范围 | 禁止新处理，清理来源和派生引用 | 与写命令共用锁顺序；后台清理可恢复 |

## 适配器约束

存储必须支持事务回调、唯一键和条件版本更新；禁止以降级到另一权威库处理失败。模型和食品适配器返回来源、截止时间及结构化失败；不得持有数据库写锁。身份适配器在演示与托管中分别配置，演示身份不对公网作为真实认证。时钟可替换以验证截止、跨周和迟报。

## 任务恢复

任务只保存必要进度和引用，草稿带来源与授权版本。回到任务时先检查当前归属和授权，再返回仍有效的步骤；过期部分重新核对。每次请求持有独立上下文，不依赖共享的活动用户或活动任务变量。
