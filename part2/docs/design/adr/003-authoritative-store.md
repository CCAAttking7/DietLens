# ADR-003 每种部署只使用一个权威业务库

状态：用户在P3成果展示后要求“继续”，本决策沿用进入P4。日期：2026-11-17。

## 背景与决定

本地演示使用本机SQLite并启用WAL；托管目标使用PostgreSQL。它们代表不同部署，不同时写入或遇错自动切换。存储接口需表达事务、条件版本更新、唯一约束和一致快照，不能仅提供不具备提交语义的对象读写。

## 备选与影响

统一使用PostgreSQL减少数据库差异，但增加离线课堂演示环境成本。双库自动回退会分裂事实和回执，不采用。SQLite仍只有一个并发写者，必须短事务、有界忙等待且数据文件不放网络盘。PostgreSQL默认隔离级别不能替代版本检查。

## 验证与重审

两种适配器执行同一组事务、幂等和冲突验收；分别验证锁竞争和失败回滚。并发容量由PoC测量决定，不声称两者性能相同。P4确定字段、索引、约束、保留和备份设计；不会在本阶段创建业务库。
