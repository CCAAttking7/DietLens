# 中文界面设计稿

本目录为可编辑SVG及同版PNG静态稿，使用虚构资料，不是运行截图或已完成的用户测试。最终说明见[报告](../DietLens_Assignment2_Design.pdf)第13–18页；用户流程图见[精简源图](../final/figures/F05-flow.puml)。

| 图稿 | 重点 |
|---|---|
| U01-food | 配料未知、来源核对及手输路径 |
| U02-plan | 两人人数换算、库存未知与采购差额 |
| U03-record | 一次个人用餐含多种食物，份量独立核对 |
| U03M-record-mobile | 390像素单列实际记餐 |
| U04-feedback | 执行日期、互斥反馈及已确认窗口 |
| U05-review | 执行周、结束队列、预期槽位及营养缺口 |
| U06-recovery | 提交后断网，按原键核对保存结果 |
| U07-adoption | 线索、行为、努力量、依据及可修改行动窗口 |

界面和结构化卡片采用同一暖米、陶土和绿色方向；状态同时用文字表达。焦点、读屏、缩放和触控行为需第三部分在可运行原型验证。重建命令为python part2/tools/render_ui_mockups.py。
