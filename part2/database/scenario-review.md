# 数据库语义走查

版本：R2-P4候选。以下是设计审查及后续验收断言，不是已执行数据库测试。静态结构核对见[检查记录](validation.json)。

| 场景 | 设计结果 | 保障与后续断言 |
|---|---|---|
| DB-01 甲的餐食引用乙的计划 | 拒绝跨用户关系 | 复合归属外键；后续引擎负例 |
| DB-02 当前修订指向不存在版本 | 事务不得提交 | 延迟外键；同事务写入身份与首版 |
| DB-03 修改单项食物 | 同餐食新增完整版本 | 当前指针切换，旧版不重复计餐 |
| DB-04 同午餐记两次用餐 | 保存两身份，槽位覆盖一次 | 用餐不设日期槽位唯一；回顾集合去重 |
| DB-05 删除最后食物 | 不形成空的确认餐食 | 命令校验至少一项；整餐删除另行确认 |
| DB-06 两人备餐每人150克 | 总需求300克 | 人数与每人/本餐总量基准，由模块换算一次 |
| DB-07 已知需求另有未知配方 | 已知小计可见，完整差额未知 | has_unknown_requirement与联合检查 |
| DB-08 未登记库存 | 库存与差额未知 | 不创建零库存来补缺省 |
| DB-09 勾选已买或已准备 | 只改该类自述 | 不扣库、不记餐、不写行动执行 |
| DB-10 仅替换明天午餐 | 只变更对应槽位 | 槽位主键与复合餐次引用；旧计划内容保持 |
| DB-11 重建失效清单 | 新清单核对，旧已购不自动继承 | 同来源版本一份有效清单；独立新确认 |
| DB-12 完整周只有20餐 | 阻止确认，保留临时草案 | 事务内3/21餐计数；不由CHECK冒充保障 |
| DB-13 指定明天午餐一餐 | 验所选集合即可 | 模式字段和确认餐次集合；不套21餐要求 |
| DB-14 尚未采纳就报完成 | 拒绝 | 决策引用及采纳守卫；FK本身不验证决策内容 |
| DB-15 迟报、修正或撤回执行 | 原行动新增修订，贡献只取当前项 | 当前执行外键及预期版本；不复制成功 |
| DB-16 窗口跨周修正 | 更新结束队列，执行日期不移动 | 两类修订表分开；原/新周失效 |
| DB-17 窗口到期但无反馈 | 派生未知，仍在结束分母 | 不由提醒事件写未完成 |
| DB-18 同键双击/断网重试 | 一份提交和回执 | 主键、请求摘要、同库事务；后续竞争与故障注入 |
| DB-19 同版本不同命令竞争 | 仅合法版本更新，另一项冲突 | 条件更新及受影响行数；用户域处理顺序 |
| DB-20 关闭历史后恢复任务 | 不使用旧历史权限 | 当前授权标记；绑定过期草稿需重新核对 |
| DB-21 图片24小时到期 | 无法取回文件或再外传 | 文件清理、空键、状态和截止检查；核对字段按自身期限处理 |
| DB-22 删除来源后读旧回执 | 不恢复已删敏感内容 | 回执只保留必要引用；恢复重新授权与检查有效性 |
| DB-23 七天任务清理后查回执 | 原回执仍可在授权内查 | 先置空任务引用，再删临时态 |
| DB-24 回执也到期后重放旧确认 | 返回过期，不能作新提交 | 首次写须绑定仍有效的服务端任务与操作标识 |
| DB-25 从旧备份恢复已删除用户 | 重放删除/到期清单后才开放 | 最小化抑制标记、最长30天备份及恢复复核 |
| DB-26 仅计划到期，实际有个人自述 | 实际事实保留，解除已过期可选出处 | 依赖清理清单；不以计划生命周期删除实际摄入 |

未知规则继续保留在正文TBD区。题库内容、排序权重、备份介质没有用虚构配置填入设计。
