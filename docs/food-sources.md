# 食品资料与安全门

## 支持的来源

Open Food Facts 适配器支持条码详情和结构化搜索，保留产品名称、来源 ID、配料、过敏原、营养字段、规格、抓取时间和原始响应。其用户贡献数据只作为候选资料，不能自动解除过敏限制。

中国疾控公共卫生科学数据中心适配器下载食物编码表到本地并索引；该资源当前主要提供编码/分类，缺少当前商品配料和营养时会保留未知。基础数据不会覆盖用户当次提供的包装标签、菜单或份量。

兼容的 USDA 类适配器只保留旧测试注入用途，默认注册表不启用；本项目运行不依赖 USDA。

## 查询结果

`FoodSourceRegistry.search` 返回记录和按来源归类的失败。相同来源、关键词和数量在 TTL 内使用缓存；缓存不是新的事实来源，记录中的 `retrieved_at` 仍指向实际观察时间。查询结果可通过 `food.search_result` 加入预算与硬约束安全门，再通过 `persist_search_result` 写入观察表。

安全状态含义：

- `safe`：当前已确认硬约束下没有命中，且关键配料/过敏原字段可用。
- `blocked`：明确命中过敏或绝对忌口，或已知价格超出预算。
- `needs_confirmation`：关键字段未知，硬约束尚未确认，或必须由用户核对包装标签。

安全门只针对硬约束。软偏好用于后续候选排序，不会把食物过滤掉。英文过敏原标签会归一到常见中文词（例如 peanuts→花生）；未知语言、复合配料和交叉污染声明仍需人工核对。

营养比较要求字段和单位一致，当前只接受同一 `per_100g` 或 `per_100ml` 语义；不会把克和毫升自动换算。缺失营养值继续为 `None`，不会填零。

跨来源同名记录不自动合并。规格或单位冲突生成冲突对象，界面应同时显示来源和来源 ID。相似商品不是同一商品。

## 本地烟测

当前环境查询“燕麦”时，Open Food Facts 失败被隔离；中国疾控编码表返回“燕麦片”，但因没有当前商品配料和过敏原字段而标为 `needs_confirmation`。系统没有把它自动推荐。

## 当前限制

食品观察表是查询事实的审计记录，不是计划、采购清单、库存或实际餐食记录。包装标签核对、价格来源、完整营养索引、图片输入和食品专用 API 仍按后续切片实现。模型可以帮助提取用户文字，不能放行安全门或计算营养。
