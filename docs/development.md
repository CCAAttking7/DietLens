### 本次交付

- Python 包元数据、测试依赖、环境变量配置和忽略规则。
- SQLite 有序迁移及迁移台账，兼容已有无版本 MVP 数据库；启动自动迁移，迁移失败回滚。
- Repository Protocol；SQLite 直接读取数据库，取消业务对象的进程内镜像缓存。
- 任务、行动、操作回执和事件在同一事务提交；内存仓库提供一致的回滚语义。
- 任务版本检查、UTC 时间戳；两个数据库连接可读到最新状态，旧版本写入拒绝。
- 幂等操作回执完整保存原响应；重复请求不再用新输入拼装旧结果。同一操作键更换参数返回 `operation_conflict`。
- 不同任务的行动 ID 独立，避免同用户同餐次的行动互相覆盖。
- 状态迁移统一产生 `task.state_changed` 事件；迭代/工具额度耗尽可持久化停止原因。
- 工具白名单、读写分类、确认门和输入/输出 JSON Schema 校验。
- 模型 Provider Protocol、Stub 和结构化意图校验；非法输出或模型故障进入手动澄清，不写行动。每步骤模型上限 2 次，工具上限 3 次；模型额度耗尽后确定性用户操作仍可继续。
- 结构化日志只记录任务 ID、步骤提交或错误码；不输出原始模型消息、档案或食品输入。
- CLI 支持 `--resume TASK_ID`，可从待确认、待反馈或已反馈状态继续。
- 固定合成回放样例与内存/SQLite 双实现测试。

## 阶段 2：食品资料查询与安全门（当前增量）

- `FoodSourceRegistry` 对 Open Food Facts、中国疾控本地索引和显式注入的兼容源做只读 fan-out；默认不启用 USDA，避免引入计划外运行依赖。
- 查询参数有长度边界；来源请求失败按来源隔离，向上层只返回稳定错误码，不泄露响应内容。
- 进程内有界 TTL 查询缓存，避免同一来源/关键词/数量重复请求；缓存可清空，外部来源仍保留抓取时间。
- `FoodAssessment` 将记录分成 `safe`、`blocked`、`needs_confirmation`。明确过敏/绝对忌口命中即阻断；关键配料或过敏原缺失时停止受影响推荐；未确认的硬约束不会自动晋级为安全。
- 过敏原支持常见英文 Open Food Facts 标签到中文约束词的归一；软偏好不参与硬过滤。
- 已知商品价格超过预算时阻断；价格未知保持未知，不把未知当作零。营养字段保持 `None`；`g` 与 `mL` 不做无依据换算。
- 同名跨来源的规格差异生成 `SourceConflict`，来源 ID 与字段值并列展示，不自动合并相似商品。
- 新增 `food_observations` 迁移和 Repository 接口；每次查询结果可保存来源、来源 ID、原始响应、抓取时间、状态和未知字段。观察保存不等于推荐确认、采购或实际摄入。
- CLI 食品查询显示来源、状态、未知字段和营养值，仅将 `safe` 记录作为自动候选；约束未知时明确转人工标签核对。

本增量测试结果：132 项通过。阶段 2 尚未完成完整中国营养成分数据下载索引、当前商品标签确认界面、价格来源适配和食品字段专用 API；这些仍需继续按来源与授权边界接入。模型 food 路由已经预留，但安全过滤与数值计算不交给模型。


真实只读来源烟测：查询“燕麦”时 Open Food Facts 在当前网络返回 `open_food_facts_request_failed`，中国疾控本地索引返回“燕麦片”（来源 ID `15-2-103`）；因该编码表没有当前商品配料/过敏原，结果被标为 `needs_confirmation`，没有进入安全候选。这符合失败隔离和未知字段安全门。

## 阶段 5：反馈修正与下一候选的最小闭环

- 反馈支持 `complete`、`partial`、`not_done`、`unknown`；可附带用户自述障碍，但障碍不会写回档案。
- 每个行动保留反馈历史；迟到反馈通过原任务和原行动修正，回顾 revision 随当前行动版本重新计算，不生成重复行动。
- `partial`/`not_done` 只让下一次同情境候选优先尝试其他选项；行动保存冷却截止时间，不会永久屏蔽选项，也不会把一次障碍当作失败标签。
- 提醒使用 1/3/7/14 日退避，必须有 `reminders` 授权；没有授权时状态和发送入口都被阻止。
- 重复完成或重复遇阻只生成“待确认的偏好信号”；`/api/preferences/suggestions` 是只读接口，不会自动修改档案。
- Web 反馈文案明确“没有正确答案”，回顾展示的是用户愿意留下的部分；实际餐食记录仍是独立确认入口。

本增量验收：180 项测试通过，覆盖障碍只影响下一候选、迟到反馈、同一行动修正、反馈历史、回顾重算、提醒授权、提醒退避、冷却过期、四维行动轮换和偏好信号确认边界。
